OpenBMC for Nuvoton NuMaker Platforms

Repository setup, Path A (Ubuntu 24.04 / Docker build), Path B (CI artifacts), and Windows NuWriter procedure

BoardsSetup GuideDocker SetupBSP Layers

Nuvoton OpenBMC distribution for NuMaker evaluation boards, providing Yocto/OpenEmbedded BSP layers, the Phosphor stack, Redfish, WebUI, Serial-Over-LAN (SOL), and GPIO host power control. For the visual top-view workflow diagram, see Workflow Overview.

1. Path A: Build from Source (Ubuntu 24.04 & Docker)

Environment flow: Ubuntu 24.04 → Docker → BitBake → Image → Windows → NuWriter → Board

1.1 Clone Repository (Ubuntu 24.04 Host)

Clone the OpenBMC repository:

git clone https://github.com/OpenNuvoton/openbmc.git

Enter the repository directory:

cd openbmc

1.2 Build & Enter Docker Container (Ubuntu 24.04 Host)

Switch to the Docker directory, build the image/container, and enter it:

cd meta-numaker/doc/docker/
./build.sh
./join.sh

See the Docker Environment Guide for host prerequisites, UID mapping, and container lifecycle scripts.

1.3 Compile Firmware Image (Inside Docker Container)

Inside the container, switch to ~/openbmc, initialize your target board (replace <machine> and <build-dir> per Section 4), and start compilation:

cd ~/openbmc
MACHINE=<machine> source setup <machine> <build-dir>
bitbake nuwriter-pack

1.4 Build Outputs & Next Step

Generated images and Windows flashing scripts are deployed to <build-dir>/tmp/deploy/images/<machine>/ on the shared host directory:

  • Flash pack images: nuwriter-pack-spinand-<machine>.bin, nuwriter-pack-nand-<machine>.bin (if supported), nuwriter-pack-sd-<machine>.bin, and bootable SD image obmc-phosphor-image-<machine>.wic.
  • Windows flashing scripts: install_nuwriter.bat and nuwriter_program_*.bat.
Next Step

Copy the deploy outputs to a local Windows folder and proceed to Section 3: Windows Flashing & Board Boot, or open your board's Quickstart / Power & Boot Settings below.

2. Path B: Use Pre-built Image (GitHub Actions)

Environment flow: GitHub Pre-built Image → Windows → NuWriter → Board

  1. Open the OpenBMC NuMaker CI Workflow (numaker.yml) and select the latest successful run.
  2. Download openbmc-<machine>.zip from the Artifacts section (a personal GitHub account sign-in is required to download GitHub Actions artifacts).
  3. Extract the archive to a local folder on your Windows PC and proceed directly to Section 3.

3. Windows Flashing & Board Boot (Shared by Path A & B)

  1. Prepare files on Windows: Place the deploy directory contents (Path A) or extracted openbmc-<machine>.zip contents (Path B) in a local Windows folder.
  2. Connect cables: Connect USB0 (Device) to the Windows PC for NuWriter, and connect the UART0 debug console (115200 8N1) via VCOM (or an external USB-to-UART dongle on CON2 PE14/PE15/VSS for MA35D05KI1). Do not connect NuWriter to VCOM.
  3. Enter USB Download Mode: Power off the board first, set the boot DIP switch to USB Download (check your board's interactive Power & Boot Settings in Section 4), then power on (on MA35D16FJ87C, press power button SW1 after connecting 5V power and confirm yellow LED3 lights up).
  4. Flash firmware on Windows: Run install_nuwriter.bat once to download NuWriter dependencies (MA35D1_NuWriter for MA35 boards, or NUC980_PyNuWriter for NUC980G2), then run nuwriter_program_spinand.bat, nuwriter_program_nand.bat, or nuwriter_program_sd.bat.
  5. Normal Boot & Verification: Power off first, switch the DIP switch to Normal Boot, and power on (press SW1 on MA35D16FJ87C). Verify boot progress on UART0 and access BMC via SSH, WebUI (MA35 boards), or Redfish (default login: root / 0penBmc).
